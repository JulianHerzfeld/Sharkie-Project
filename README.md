# Sharkie

**Sharkie** ist ein 2D-Action-Spiel auf objektorientierter Basis.  
Steuere Sharkie unter Wasser und besiege Gegner, indem du Blasen abschießt.

---

## 🎯 Zielgruppe

- Ein kleines Mini-Spiel für jeden, der Spaß an schnellen, einfachen Spielen hat

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- Keine externe Datenbank nötig

---
